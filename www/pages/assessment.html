Assessment Overview

This assessment evaluates your understanding and application of Cyber-Informed Engineering (CIE) principles. You will complete a series of interconnected tasks that simulate real-world engineering challenges in operational technology (OT) systems.

Deliverables: A comprehensive report synthesizing all task findings, including a prioritized list of mitigation strategies. See the Deliverables section below for full requirements.

Instructions

Deliverables & Grading Rubric

Report Requirements

You will submit a comprehensive report synthesizing all task findings. The report must be professionally formatted and include all required sections below.

Report Sections

Title Page: Include the assessment title, your name, and the date

Table of Contents: List all sections and their page numbers

Executive Summary: Summarize the key points of the report (300-400 words)

Tasks: Include sections for each task:

  • Task 1: Component Identification
  • Task 2: Threat Intelligence
  • Task 3: Engineering Controls
  • Task 4: Supply Chain Security

Top 10 Mitigation Strategies: Compile a prioritized list based on your findings across all tasks. Mix immediate fixes, engineering projects, and policy changes.

Acknowledgements: If using AI, acknowledge the tools and resources utilized

References: List all sources and references used in the report

Appendices: Include if necessary

Grading Rubric

Use this rubric to understand how each task will be evaluated.

Task Criterion Excellent (9-10 pts) Satisfactory (6-8 pts) Needs Improvement (0-5 pts)
Task 1 Asset Inventory Comprehensive list categorized correctly by Level (0, 1, 2). Identifies critical "kill step" assets clearly. List is present but lacks categorization or misses key assets (e.g., omits the LSI Gateway). Incomplete list; confuses IT assets (printers) with OT assets (PLCs).
Task 2 Threat Mapping Connects specific scenario facts (e.g., "VPN to Resource LAN") to specific consequences. Identifies specific actors. Generic threat list (e.g., "Hackers could attack"). Lacks specific attack vectors from the topology. Vague or theoretical only. No reference to the SSS scenario.
Task 3 CIE Controls Proposes valid physical/mechanical controls (fuses, clutches, valves) that mitigate specific scenario physics risks. Proposes controls, but relies heavily on digital solutions (firewalls/passwords) rather than engineering controls. Fails to identify physical risks. Proposes standard IT security measures only.
Task 4 Supply Chain Deeply analyzes specific vendor risks (LSI credentials, Golden Bake telemetry, OpenPLC). Identifies the vendors but lists generic risks (e.g., "Vendor might get hacked"). Fails to address the specific vendors listed in the scenario.
Report Structure & Quality Professional formatting, includes Executive Summary and "Top 10" list. Clear, concise writing. Follows structure but lacks polish or Executive Summary is weak. Missing sections (e.g., no Top 10 list); poor formatting.
