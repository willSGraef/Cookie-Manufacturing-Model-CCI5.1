Welcome to the Cyber-Informed Engineering (CIE) Assessment Platform

A comprehensive workstation-based learning experience for students to master CIE concepts and skills.

Getting Started

Welcome! This platform guides you through an CIE assessment using your workstation. Make sure all required software is installed before beginning. Please read through the entire scenario before starting any of the assessment items.

System Requirements

  • OpenPLC Runtime (installed)
  • OpenPLC Editor (installed)
  • Ignition and Ignition Designer (installed)
  • Modern web browser (Chrome, Firefox, Safari, or Edge)
  • Debian based Linux distribution (installed)

Quick Start

  1. Review the scenario details
  2. Complete the assessment tasks
  3. Submit your work through your Learning Management System (LMS) platform
