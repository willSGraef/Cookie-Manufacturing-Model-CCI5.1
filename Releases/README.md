# Installation Instructions

These instructions will guide you through the installation process for different operating systems. The steps may vary slightly depending on your specific environment. There are three files in this release:

1. `CIE Assessment Platform Setup 1.0.0.exe` - Windows installer
2. `CIE Assessment Platform-1.0.0-dmg.dmg` - macOS installer
3. `CIE Assessment Platform-1.0.0-arm64.AppImage` - Linux AppImage

## Windows

1. Download the `CIE Assessment Platform Setup 1.0.0.exe` file.
2. Double-click the downloaded `.exe` file to start the installation process.
3. Follow the on-screen instructions to complete the installation.
4. Once installed, you can find the application in your Start Menu.
5. Launch the application and follow any additional setup prompts if necessary.

## macOS

1. Download the `CIE Assessment Platform-1.0.0-dmg.dmg` file.
2. Double-click the downloaded `.dmg` file to mount the disk image.
3. In the window that opens, drag the `CIE Assessment Platform` icon to your Applications folder.
4. Once copied, you can eject the disk image by right-clicking on it and selecting "Eject".
5. Open your Applications folder and double-click the `CIE Assessment Platform` icon to launch the application.
6. Follow any additional setup prompts if necessary.

## Linux

1. Download the `CIE Assessment Platform-1.0.0-arm64.AppImage` file.
2. Open a terminal and navigate to the directory where the AppImage was downloaded.
3. Make the AppImage executable by running the following command:

    ```bash
    chmod +x CIE\ Assessment\ Platform-1.0.0-arm64.AppImage
    ```

4. Run the AppImage with the following command:

    ```bash
    ./CIE\ Assessment\ Platform-1.0.0-arm64.AppImage
    ```

5. Follow any additional setup prompts if necessary.
