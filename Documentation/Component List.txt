Sugar Silo; sugar_weight

	- Needs to be open or closed to facilitate the transfer of sugar from the silo to the hopper

Vacuum; vacuum, vacuum_rpm, vacuum_manual
	- If the vacuum isn't on; no material is transferred, the rate of transfer is dependent on the vacuum_rpm, and the vacuum manual determines whether the operator has 	control over the rpm of the vacuum
Hopper; hopper_weight
	- Has a max load of 40 pounds; must account for the transfer of ingredients from the hopper to the mixer, only if: hopper_weight > 0, mixer + new material < 60, rv_3 = 	open
Hopper Rotary Valve; rv_3
	- Is either open or closed to facilitate the transfer of ingredients from the hopper to the mixer
Mixer; mixer, mixer_rpm, mixer_weight

	- Must account for the transfer of dough to the wirecutter trough; if trough_transfer is true; move dough from mixer to the wirecutter trough

Execution pattern:
	- Pull all owned signals from OpenPLC
	- Pull all relevant signals from redis server
	- Perform relative operations based on shared values
	- Push all owned signals to OpenPLC
	- Push all signals to redis server

Step 1: Develop/Run redis signal bus which has all shared signals
Step 2: Update resource area to have logic separated into 10 different programs, with 10 different modbus servers for OpenPLC to poll from
Step 3: Repeat Step 2 for Production and Finished Good areas
Step 4: Develop docker compose file to generate containers for each program
	- Each container runs it's specific program from a shared folder which all containers have access to
